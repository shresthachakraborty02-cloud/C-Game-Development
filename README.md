# C-Game-Development
A C-based cognitive game for exploring attention, reaction time, memory, and task engagement through simple, low-pressure challenges inspired by difficulties commonly associated with Major Depressive Disorder (MDD).

1. Reaction Timer
Tests attention and reaction consistency. A prompt appears after a random delay, player hits Enter as fast as possible. Score increases with faster reaction times, tracked across rounds to measure consistency over time.
MDD often slows processing speed and blunts attentional focus. Short, low-stakes rounds give a quick way to notice engagement and responsiveness in the moment, without demanding much effort or commitment — useful for someone whose motivation is low.

2. Number Spotter
Tests attention and task completion. A grid of numbers appears, player finds a target number. Grid size increases each level — gradual progression, with points awarded based on how quickly the target is found.
Concentration and sustained attention are commonly affected in MDD. This game breaks focus into small, achievable chunks (find one number, done) rather than requiring long stretches of concentration, which mirrors how small task completion can rebuild a sense of accomplishment.
